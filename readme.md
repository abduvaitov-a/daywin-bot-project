# 🔥 DAYWIN - Telegram-бот для трекинга привычек

DAYWIN - это удобный и мотивирующий Telegram-бот для формирования полезных привычек, отслеживания прогресса и ежедневной дисциплины. 

Проект разработан на **Python** с использованием современных библиотек и архитектурных подходов.

---

## 🚀 Основные возможности

- **Управление привычками:** Создание до 5 активных привычек одновременно.
- **Гибкие сроки:** Выбор стандартного периода (1, 3 или 6 месяцев) либо ввод кастомного количества дней.
- **Уведомления:** Автоматические утренние напоминания и вечерние отчёты через встроенный планировщик (`APScheduler`).
- **Статистика и прогресс:** Подсчет успешности выполнения привычек в процентах, учет пропусков и оставшихся дней.
- **Система достижений:** Перенос выполненных привычек в отдельный список достижений.

---

## 🛠 Технологии

- **Python 3.10+**
- **Aiogram 3** (асинхронный фреймворк для Telegram-ботов)
- **SQLite & FSM** (база данных и машины состояний)
- **APScheduler** (планировщик фоновых задач)
