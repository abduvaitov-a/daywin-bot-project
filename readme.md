# 🔥 DAYWIN — Telegram-бот для трекинга привычек

DAYWIN — это удобный и мотивирующий Telegram-бот для формирования полезных привычек, отслеживания прогресса и ежедневной дисциплины[cite: 10]. 

Проект разработан на **Python** с использованием современных библиотек и архитектурных подходов.

---

## 🚀 Основные возможности

* **Управление привычками:** Создание до 5 активных привычек одновременно[cite: 10].
* **Гибкие сроки:** Выбор стандартного периода (1, 3 или 6 месяцев) либо ввод кастомного количества дней[cite: 10].
* **Уведомления:** Автоматические утренние напоминания и вечерние отчёты через встроенный планировщик (`APScheduler`)[cite: 10].
* **Статистика и прогресс:** Подсчет успешности выполнения привычек в процентах, учет пропусков и оставшихся дней[cite: 10].
* **Система достижений:** Перенос выполненных привычек в отдельный список достижений[cite: 10].

---

## 🛠 Технологии

* **Python 3.10+**[cite: 10]
* **Aiogram 3** (асинхронный фреймворк для Telegram-ботов)[cite: 10]
* **SQLite & FSM** (база данных и машины состояний)[cite: 10]
* **APScheduler** (планировщик фоновых задач)[cite: 10]
